## 记忆文件层级

```
memory/
│
├── SOUL.md           L0 身份层 — 用户手动编辑
│   ├─ 关于我 / 兴趣领域 / 不感兴趣
│   └─ 系统永不覆盖，首次从模板初始化
│
├── PROFILE.md        L1 画像层 — 系统自动生成
│   ├─ 阅读概览 / 订阅源偏好 / 话题偏好
│   ├─ AI 洞察 / 搜索兴趣 / 压缩摘要
│   └─ 每日维护更新，quickRefresh 局部修补
│
├── LESSONS.md        L2 经验层 — 推荐效果追踪
│   ├─ 成功模式 / 反模式 / 推荐优化（待 AI 填充）
│   └─ 推荐效果追踪表（每日命中率自动写入）
│
├── MEMORY.md         ★ 共识层 — 蒸馏所有层洞察
│   ├─ 推荐策略（自适应权重 + 置信度）
│   ├─ 兴趣地图（核心 / 新兴 / 衰减）
│   ├─ 优质来源排行 + 推荐维度效果
│   └─ 每次画像更新后自动重新生成
│
├── LEARNING.json     ★ 学习状态 — 跨会话持久化
│   ├─ 自适应权重 + 维度追踪器
│   ├─ 话题趋势 + 来源质量 + 策略历史
│   └─ 累计学习次数 + 权重置信度
│
├── briefing_*.json   简报缓存
│
└── daily/
    ├── 2026-05-01.md  每日行为日志
    ├── 2026-05-02.md  ├─ 时间 | 行为 | 文章 | 来源 | 时长
    └── ...            └─ 30 天自动清理
```

## 推荐引擎自学习闭环

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│   ┌──────────┐    静态权重(默认)                          │
│   │ 冷启动    │    c=0.45 t=0.30                          │
│   │ conf=0   │    f=0.20 fd=0.05                         │
│   └────┬─────┘                                           │
│        │ 用户开始阅读                                      │
│        ▼                                                  │
```

## 四层记忆 AI 上下文加载策略

```
AI 调用场景          加载层级          消耗
────────────────────────────────────────────
文章排序(rankArticles)    L0 + L1        ~300 token
文章解读(analyzeArticle)  L0 + L1        ~300 token
简报生成(generateBriefing) L0 + L1 + L2  ~500 token
画像合成(runAISynthesis)  L0 + L1 + L2   ~500 token
全量上下文(buildAIContext) L0~L3          ~800 token

L0 = SOUL 核心段（身份+兴趣，约100 token）
L1 = PROFILE 压缩摘要（权重+话题+洞察，约200 token）
L2 = 近日行为摘要（今日+昨日，约200 token）
L3 = LESSONS 经验教训（约300 token）
```
