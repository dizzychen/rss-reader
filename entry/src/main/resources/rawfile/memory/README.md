# 记忆系统 - 初始化指南

## 文件说明

本目录包含 RSS 阅读器三层记忆系统的原始模板文档：

### SOUL.md - 灵魂档案

**作用**: 记录你的本质特征，帮助 AI 理解你的价值观和长期目标

**内容**:
- 关于我：职业、背景、身份
- 阅读目的：为什么阅读
- 兴趣领域：感兴趣的话题
- 不感兴趣的内容：希望过滤的内容
- 阅读哲学：你的阅读观
- 当前关注：正在研究的问题

**更新频率**: 季度级（3 个月一次）

**使用方式**:
1. 进入设置 → 我的阅读档案
2. 编辑 SOUL.md 内容
3. 点击保存

### PROFILE.md - 画像层

**作用**: 自动记录你的近期阅读习惯和兴趣权重

**内容**:
- 阅读概览：基本统计数据
- 订阅源偏好：各来源阅读权重
- 话题偏好：感兴趣的主题分布
- 活跃时段：什么时候最爱阅读
- 阅读偏好：长度、深度、内容倾向

**更新频率**: 每日自动更新

**维护方式**: 
- **完全由系统自动生成**，用户无需手动编辑
- 首次安装时为空骨架，阅读几篇文章后自动填充
- 由 ProfileService.regenerate() 基于 30 天行为数据计算

### daily/YYYY-MM-DD.md - 日志层

**作用**: 记录每天的具体阅读行为

**内容**: Markdown 表格，包含：
- 时间戳
- 行为类型（阅读、收藏、搜索等）
- 文章信息（标题、来源）
- 阅读时长
- 行为备注

**更新频率**: 实时记录

**自动清理**: 30 天自动删除旧日志

---

## 三层记忆架构

```
灵魂层 (SOUL.md)
   ↓
  你的本性
  价值观、思维方式、长期目标
  [季度更新]

画像层 (PROFILE.md)
   ↓
  你的近况
  兴趣权重、阅读习惯、近期关注
  [每日自动更新]

日志层 (daily/*.md)
   ↓
  你的今天
  具体阅读行为、时间、时长
  [实时记录]
```

## 存储位置

运行时会存储在应用沙箱目录：

```
{context.filesDir}/memory/
├── SOUL.md
├── PROFILE.md
└── daily/
    ├── 2026-03-21.md
    ├── 2026-03-20.md
    └── ...
```

设备上的真实路径（Stage 模型）：

```
/data/storage/el2/base/files/memory/
```

## AI 个性化推荐工作流

```
1. 用户打开首页
   ↓
2. 系统读取：SOUL.md + PROFILE.md + 今日日志
   ↓
3. 构建 AI 上下文（完整理解用户）
   ↓
4. 调用通义千问 API
   ↓
5. AI 为每篇文章打分
   ↓
6. 按分数降序排列展示
```

## 功能特性

| 功能 | 说明 |
|------|------|
| **智能排序** | 首页文章按个性化推荐排序 |
| **每日简报** | AI 生成符合口味的早间简报 |
| **精读辅助** | 阅读时提供个性化解读 |
| **成长洞察** | 查看阅读画像和统计数据 |
| **数据管理** | 导出或清除所有记忆数据 |
| **隐私保护** | 所有数据本地存储，不上传云端 |
